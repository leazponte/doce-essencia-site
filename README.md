# Site Doce Essência

Site estático da Doce Essência, confeitaria artesanal em Teresópolis.

- `index.html`: página única (produtos, kit festa, galeria, pedido pelo WhatsApp, depoimentos, sobre, dúvidas)
- `img/`: fotos do site
- Telefone do WhatsApp: variável `FONE` no fim do `index.html`

Publicação: Cloudflare Pages ligado a este repositório, sem comando de build e com pasta de saída `/`.
Todo envio para a branch `main` publica o site automaticamente.
